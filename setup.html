每日運動紀錄 — Google 登入設定說明

跑一次以下設定，之後你和朋友都能用自己的 Google 帳號登入，紀錄各自存在自己的雲端硬碟。

先看這裡：資料存在哪、誰看得到

每個人的紀錄存在他自己 Google 雲端硬碟的「應用程式資料」隱藏區（appDataFolder）。這是一塊只有本應用程式讀得到的空間，不會出現在雲端硬碟的檔案清單裡，你（開發者）也讀不到任何人的資料，因此不需要伺服器、沒有主機費用，也不用替別人的個資負責。

需要的檔案

檔案用途
index.html應用程式本體（全部功能都在這一個檔案裡）
啟動運動紀錄.bat雙擊即可在本機開一個網址 http://localhost:8080
server.js / serve.ps1啟動用的小程式，讓 .bat 在有 Node.js 或只有 Windows 內建環境時都能跑

四個檔案要放在同一個資料夾。

為什麼不能直接雙擊 index.html？

Google 登入只允許來自「網址」（http / https）的請求。直接開啟檔案時網址是 file:///C:/...，Google 一定會拒絕。所以要用 啟動運動紀錄.bat 讓它變成 http://localhost:8080。

設定步驟（約 10 分鐘，只需做一次）

1 建立 Google Cloud 專案

  1. 開啟 Google Cloud Console，用你的 Google 帳號登入
  2. 左上角專案選單 → 新增專案 → 名稱填 Fitness Record → 建立
  3. 建立完成後，確認右上角已切換到這個專案

2 啟用 Google Drive API

  1. 左側選單 → API 和服務 → 程式庫
  2. 搜尋 Google Drive API → 點進去 → 啟用

3 設定 OAuth 同意畫面

  1. API 和服務 → OAuth 同意畫面
  2. 使用者類型選 外部（External） → 建立
  3. 應用程式名稱填「每日運動紀錄」，使用者支援電子郵件與開發人員聯絡資訊填你的 Gmail
  4. 「範圍」這一步可以直接略過（本程式會在登入時自行要求，不必預先加入）
  5. 「測試使用者」加入要使用的人的 Gmail（含你自己）

關於審查與人數上限

  • 本程式只使用 非敏感範圍：drive.appdata（App 專用隱藏區）與 openid / email / profile。Google 把 drive.appdata 歸類在建議使用的非敏感範圍，不需要通過 Google 的敏感／受限範圍審查。
  • 測試模式：最多 100 位測試使用者，登入時會看到「Google 尚未驗證這個應用程式」的提醒，按「進階 → 繼續前往」即可。
  • 人變多時可在同意畫面按 發布應用程式（正式版）。因為只用非敏感範圍，不必送出審查表單，警告畫面也會消失。

4 建立 OAuth 用戶端 ID

  1. API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID
  2. 應用程式類型選 網頁應用程式
  3. 已授權的 JavaScript 來源按「新增 URI」，填入：
    http://localhost:8080
  4. 已授權的重新導向 URI 不用填（本程式用的是瀏覽器端 Token 流程）
  5. 建立後複製那串 xxxxxxxx.apps.googleusercontent.com

日後若要放到網路上（例如 GitHub Pages），回到同一個用戶端 ID，在「已授權的 JavaScript 來源」再加上那個網址即可，例如 https://你的帳號.github.io（只填到網域，不含路徑）。

5 啟動並登入

  1. 雙擊 啟動運動紀錄.bat，會跳出一個黑色視窗（使用期間請不要關閉）並自動打開瀏覽器
  2. 第一次會看到「填入 Google 用戶端 ID」，貼上剛剛複製的字串 → 儲存
  3. 按 使用 Google 帳號登入 → 選帳號 → 若出現未驗證提醒，按「進階 → 繼續前往」→ 允許存取「應用程式資料」
  4. 進入主畫面，右上角出現你的名字與同步狀態，就完成了

想讓朋友不用自己貼用戶端 ID？

用記事本打開 index.html，搜尋 CLIENT_ID: ""，把你的用戶端 ID 填進去存檔，之後任何人打開都直接看到登入按鈕。用戶端 ID 本來就會出現在網頁原始碼裡，屬於公開資訊，不是密碼。

分享給其他人

方式做法適合
對方也在自己電腦跑把整個資料夾壓縮寄給他，對方雙擊 .bat 即可（他的網址一樣是 localhost:8080，不必再改設定）幾個朋友
放到 GitHub Pages見下一節，免費、有 HTTPS、手機也能用公開分享

兩種方式的資料都存在使用者自己的雲端硬碟，換裝置登入同一個 Google 帳號就會同步。

放上 GitHub Pages

以下用帳號 daniellllin、repo 名稱 fitness-record 為例，完成後網址是 https://daniellllin.github.io/fitness-record/。

1 建立 repository

  1. 登入 GitHub → 右上角 ＋ → New repository
  2. Repository name 填 fitness-record（不能有空格，小寫加連字號最保險）
  3. 選 Public（免費帳號的 Pages 需要公開）
  4. 不用勾 Add a README（我們自己上傳）→ Create repository

2 上傳檔案

  1. 在空的 repo 畫面點 uploading an existing file（或 Add file → Upload files）
  2. 把這些檔案一起拖進去：index.html、setup.html、README.md、.nojekyll、server.js、serve.ps1、啟動運動紀錄.bat
  3. 下方 Commit changes → Commit changes

若拖不進 .nojekyll（Windows 會把它當隱藏檔），可略過，或用 Add file → Create new file 命名為 .nojekyll 留空存檔。這個檔只是告訴 GitHub 不要用 Jekyll 處理，對本專案影響不大。

3 開啟 Pages

  1. repo 上方 Settings → 左側 Pages
  2. Source 選 Deploy from a branch
  3. Branch 選 main、資料夾選 / (root) → Save
  4. 等 1～2 分鐘重新整理，頁面上方會出現網址 https://daniellllin.github.io/fitness-record/

4 把網址加入 Google 授權來源

  1. Google Cloud Console → API 和服務 → 憑證 → 點你的 OAuth 用戶端 ID
  2. 「已授權的 JavaScript 來源」新增 https://daniellllin.github.io
    只填到網域，不要加 /fitness-record，也不要有結尾斜線
  3. 儲存（可能要等 1～2 分鐘生效）

5 讓朋友不用自己貼用戶端 ID

  1. 在 repo 點開 index.html → 右上角鉛筆圖示 Edit
  2. 按 Ctrl+F 找 CLIENT_ID: ""
  3. 改成 CLIENT_ID: "你的用戶端ID.apps.googleusercontent.com"
  4. Commit changes，等 1 分鐘後重新整理網站

臨時要分享也可以用網址參數：https://daniellllin.github.io/fitness-record/?client_id=你的用戶端ID，打開一次就會記在該瀏覽器裡。

6 讓朋友能登入

OAuth 同意畫面若還在測試狀態，只有被加入「測試使用者」的 Gmail 能登入（上限 100 人），其他人會看到「存取遭到封鎖」。要開放給所有人，到 OAuth 同意畫面 按 發布應用程式；因為只用非敏感範圍，不需要送出審查。

之後要更新網站內容

在 repo 點該檔案 → 鉛筆 Edit 改完 Commit，或用 Add file → Upload files 上傳同名檔案覆蓋。約 1 分鐘後生效（瀏覽器可能要用 Ctrl+Shift+R 強制重新整理）。

常見問題

登入時出現 Error 400: redirect_uri_mismatch 或 origin mismatch

「已授權的 JavaScript 來源」與你實際使用的網址不一致。請確認填的是 http://localhost:8080（沒有結尾斜線、不是 127.0.0.1、不是 https）。剛改完設定可能要等 1～2 分鐘生效，再重新整理。

畫面顯示「⚠ 目前是用直接開啟檔案的方式執行」

你雙擊的是 index.html。請改雙擊 啟動運動紀錄.bat。

黑色視窗閃一下就關掉 / 網頁打不開

代表電腦沒有 Python 也沒有 Node.js，且 PowerShell 備援被擋下。最簡單的解法是安裝 Python（安裝時記得勾選 Add Python to PATH），再重新雙擊 .bat。

右上角顯示「同步失敗，點我重試」

多半是登入憑證過期（每次登入約 1 小時）或暫時斷網。點一下那個標籤就會重新同步；紀錄在本機還有一份快取，不會遺失。若仍失敗，到「資料備份」按 立即同步，或重新登入。

換一台電腦看不到紀錄

確認登入的是同一個 Google 帳號，並在「資料備份」按一次 立即同步。兩台裝置分別新增的紀錄會自動合併，刪除也會同步（不會復活）。

怎麼收回這個應用程式的權限？

到 Google 帳戶 → 第三方應用程式 移除授權。要一併刪掉雲端資料，可在雲端硬碟 設定 → 管理應用程式 選擇刪除隱藏的應用程式資料。

資料會佔用我的雲端空間嗎？

會，但極少。一整年的紀錄大約只有幾百 KB。

資料格式為單一 JSON 檔（fitness-record.json），隨時可在「資料備份」匯出 JSON 或 CSV，不會被綁死在這個工具裡。
